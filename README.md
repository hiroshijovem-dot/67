# Attempt 47 — a blocky obby Short, made 100% in code

A 29.5 s vertical (1080×1920, 30 fps) Short. No game engine editor, no image, model or audio files:
every block, face, particle, caption, note and sound effect is generated by the code in `src/`.

**Story:** Tim joins his first obby. A show-off pro drops in, speedruns to the top and taunts him.
Tim falls in the lava... 47 times. On attempt 47 he makes every jump, startles the pro off the
platform into the lava, and grabs the trophy. The pro respawns: "...attempt 2". *Never give up.*

| File | What it does |
|---|---|
| `src/scene.js` | three.js world, characters, animation timeline, camera shots, particles, 2D captions/bubbles. Every frame is a pure function of time `t`. |
| `src/render.mjs` | Serves the scene to headless Chromium (Playwright) and saves each frame as a JPEG. Also exports the timeline events. |
| `src/audio.py` | Synthesizes the chiptune score, SFX and gibberish voices with numpy, timed from the exported events. |
| `build.sh` | Runs everything and muxes with ffmpeg → `output/attempt47_short.mp4`. |

```bash
./build.sh
```

Requires Node 18+, Playwright + Chromium, Python 3 with numpy, and ffmpeg. Rendering takes ~6 min on 4 CPU cores (software WebGL).
